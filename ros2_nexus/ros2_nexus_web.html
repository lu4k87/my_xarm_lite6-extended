Was startet das DEV Setup?

  • Terminal 1-2: Web-Interface & ROS Bridge
    - rosbridge_websocket (rosbridge_websocket_launch.xml)
    - Robot Control Web UI (http.server Port 8081)
  • Terminal 3: MoveIt Servo Base
    Launch: _robot_moveit_servo_fake.launch.py (bzw. realmove) startet:
    - controller_manager (ros2_control_node)
    - servo_node (MoveIt Servo C++ Komponente)
    - xarm_joystick_input (Gamepad C++ Treiber)
    - collision_checker (checker.py)
    - rviz2 (Visualisierung)
  • Terminal 4: Motion Planning
    Launch: standalone_move_group.launch.py startet:
    - move_group (MoveIt 2 Planungs-Server)
  • Terminal 5-8: Assistenz- & Steuerungs-Nodes
    - scene_objects_node (rviz_marker_static_scene_objects.launch.py)
    - robot_motion_handler_movegroup (robot_motion_handler_movegroup.py)
    - scan_trajectory_node (C++ Scan Generator)
    - servo_status_overlay (rviz_overlay.py HUD)
  • Terminal 9-10: 3D Vision & Grasping Pipeline
    Launch: zed_cam_rviz_pointcloud_tf_yolo_planned_grasp.launch.py startet:
    - zed_wrapper_node / fake_camera (Kamera-Treiber)
    - tf_camera_to_robot (tf_camera_to_robot.py)
    - yolov8_3d_node (yolov8_3d_node.py)
    - yolo_planned_grasp_executor (yolo_planned_grasp_executor.py)
    - pointcloud_tf_tuner (Collision Tuning)
  • Terminal 11-12: Voice Control & AI
    Launch: Whisper Bringup & Listener starten:
    - whisper_server (OpenAI Whisper Engine)
    - voice_command_listener (Grasp Object Voice Trigger)
Unterschied: Im FAKE-Modus wird ein simulierter Arm geladen. Im REAL-Modus verbindet sich der Hardware-Treiber via TCP/IP mit dem echten xArm Lite 6.
